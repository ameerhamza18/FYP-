# 📱 TrustLayer: Phone Testing Guide (Pro Tip)

## 🎯 Goal: Run the app on a physical phone to save 15-20GB of disk space.

### 🛠️ Step 1: Prepare Your Android Phone
1.  **Enable Developer Mode**:
    *   Settings -> About Phone -> Software Information -> Tap **Build Number** 7 times.
2.  **Enable USB Debugging**:
    *   Settings -> Developer Options -> Toggle **USB Debugging** to **ON**.

### 🔌 Step 2: Connect to Your Computer
1.  Connect via USB cable.
2.  On the phone popup, check **"Always allow from this computer"** -> **Allow**.

### 🛠️ Step 3: Minimum Software Setup
1.  Install **Android Studio**.
2.  Use **SDK Manager** to install:
    *   Android SDK Platform
    *   Android SDK Platform-Tools (essential for `adb`)
3.  **Close Android Studio** (you can now run everything from the terminal).

### 🚀 Step 4: Run the App
1.  Navigate to `apps/mobile` in the terminal.
2.  Verify connection: `flutter devices`.
3.  Launch: `flutter run`.

### ⚠️ Step 5: The "Critical" Network Step
The phone cannot use `localhost`. You must point the app to your computer's IP.

1.  **Find your computer IP**:
    *   Windows: Open CMD -> type `ipconfig` -> look for **IPv4 Address** (e.g., 192.168.1.15).
2.  **Update Flutter Code**:
    *   Change `http://localhost:8001` to `http://<YOUR_IP>:8001`.
3.  **Requirement**: Phone and Computer **must** be on the same Wi-Fi.
